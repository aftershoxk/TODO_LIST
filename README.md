# TODO List — планировщик задач на Go

Дипломный учебный проект.  
Веб-приложение для управления задачами с REST API, поддержкой повторяющихся событий, аутентификацией и возможностью запуска в Docker.

---

## Описание проекта

Проект представляет собой серверное приложение на языке Go, предоставляющее HTTP API и веб-интерфейс для работы со списком задач.  
Задачи могут быть одноразовыми или повторяющимися по заданным правилам (дни, недели, месяцы, годы).  
Данные хранятся в базе SQLite.

В проекте реализованы:
- REST API
- работа с датами и расписаниями
- middleware для аутентификации
- JWT-аутентификация по паролю
- контейнеризация с использованием Docker

---

## Используемые технологии

- Go 1.22
- net/http
- SQLite (modernc.org/sqlite)
- JWT (github.com/golang-jwt/jwt)
- Docker
- HTML / JavaScript (frontend)

## Конфигурация

Приложение настраивается через переменные окружения.

| Переменная | Назначение |
|-----------|------------|
| TODO_PORT | Порт HTTP-сервера |
| TODO_DBFILE | Путь к файлу SQLite базы данных |
| TODO_PASSWORD | Пароль для аутентификации (если пустой — аутентификация отключена) |

Переменные окружения задаются при запуске

## Аутентификация

Аутентификация включается при наличии переменной окружения TODO_PASSWORD.

Механизм работы:
1. Клиент отправляет POST-запрос на `/api/signin` с JSON-объектом:
   ```json
   { "password": "..." }
2. Сервер сравнивает пароль с TODO_PASSWORD.

3. При успешной проверке формируется JWT-токен.

4. Токен возвращается клиенту и сохраняется в cookie token.

5. Все защищённые API-запросы проверяют наличие и валидность токена.

При ошибке аутентификации сервер возвращает HTTP 401.
